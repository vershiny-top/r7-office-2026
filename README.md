# R7-Office: очистка и нормализация данных

Полуфинальное задание «Интерактивная аналитика: создание дашбордов на Р7-Офис» на Волга-ИТ 2026.

Задача: из четырёх «грязных» txt-выгрузок собрать нормализованную книгу
`Результат.xlsx` с очищенными данными, справочниками и итоговым дашбордом.

## Результат работы

Файл `Результат.xlsx` содержит:

- `Товары_очищенные`, `Поставщики_очищенные`, `Продажи_очищенные`,
  `Клиенты_очищенные` - нормализованные данные.
- `Справочники` - категории, единицы измерения, статусы, города.
- `Итоговый_отчет` - сводная таблица и два графика:
  - «Объём данных до и после очистки»
  - «Ошибки по типам» (с подсветкой приоритетов)

## Как воспроизвести

### Вариант 1: макросы Р7-Офис

1. Откройте Р7-Офис → Таблицы → новый документ.
2. Импортируйте все четыре файла из `data/` как отдельные листы:
   `Данные → Из текста/CSV → разделитель ";" → кодировка UTF-8`.
3. Переименуйте листы:
   `Товары_исходные`, `Поставщики_исходные`, `Продажи_исходные`, `Клиенты_исходные`.
4. Откройте `Инструменты → Макросы → Редактор`, вставьте содержимое
   `src/macros/run_all.js`, нажмите «Выполнить».
5. Макрос создаст листы `Товары_очищенные`, `Поставщики_очищенные`,
   `Продажи_очищенные`, `Клиенты_очищенные`, `Справочники`, `Итоговый_отчет`.
6. Сохраните книгу как `Результат.xlsx`.

### Вариант 2: вручную формулами

Все очищенные листы заполняются **формулами**, а не готовыми значениями.
Откройте любой лист `*_очищенные` - увидите `=PROPER(TRIM(...))`, `=VLOOKUP(...)`
и другие формулы, которые тянут данные из соответствующего `*_исходные`.

## Что делает каждый макрос

| Макрос | Задача                                                                                                                      | Ключевые формулы                                           |
| ------ | --------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| 00     | Создать листы и справочники (категории, статусы, единицы, города)                                                           | -                                                          |
| 01     | Артикул → `АРТ-XXX`, наименование → Title Case без скобок, категория через `VLOOKUP`, цены → число, ед. изм. → `шт.`        | `SUBSTITUTE`, `PROPER`, `TRIM`, `VLOOKUP`, `VALUE`         |
| 02     | ИНН только цифры + проверка длины 10/12, телефон → `+7 (XXX) XXX-XX-XX`, Email-валидация, адрес → индекс + остаток          | `SUMPRODUCT`, `MID`, `ROW`, `INDIRECT`, `ISNUMBER`, `FIND` |
| 03     | Дата `MM/DD/YYYY` → `DD.MM.YYYY`, количество → число, `$`/`€` → рубли, статус → канон, `VLOOKUP` в каталог                  | `DATE`, `VALUE`, `IF`, `VLOOKUP`                           |
| 04     | ФИО → Title Case, даты в разных форматах, возраст + валидация 18–80, телефон/Email как у поставщиков, города по справочнику | `PROPER`, `DATEDIF`, `VLOOKUP`                             |
| 05     | Считает строки до/после и количество ошибок по типам, кладёт на лист `Итоговый_отчет`                                       | `COUNTA`, `COUNTIF`                                        |

## Сборка документа через DocBuilder

Каталог `src/doc-constructor/` - вспомогательный инструмент для генерации
финального документа в контейнере:

```bash
cd src/doc-constructor
docker compose up --build
```

## Стек
